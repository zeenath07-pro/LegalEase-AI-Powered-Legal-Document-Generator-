PROJECT TITLE

LegalEase: AI-Powered Legal Document Generator

PROJECT OVERVIEW

LegalEase is an AI-powered application designed to simplify the process of creating legal documents. It allows users to enter details such as document type, parties involved, terms and conditions, and effective date. Using Google Gemini AI, the system generates a structured legal document that can be reviewed and edited by the user. The final document can be downloaded in TXT, DOCX, and PDF formats. The application uses Streamlit for the frontend, FastAPI for the backend, and Python for development.

8 PROJECT PHASES

1. Brainstorming & Ideation Phase

The project idea was developed to create an AI-based solution for generating legal documents quickly and easily.

2. Requirement Analysis Phase

The required features, user inputs, technologies, and document export options were identified.

3. Project Design Phase

The system architecture, frontend, backend, AI integration, and document generation workflow were designed.

4. Project Planning Phase

Development tasks, tools, libraries, project structure, and implementation steps were planned.

5. Project Development Phase

The LegalEase application was developed using Python, Streamlit, FastAPI, and Google Gemini AI.

6. Project Testing Phase

The application was tested for document generation, editing, backend communication, and TXT, DOCX, and PDF downloads.

7. Project Documentation Phase

The project features, technologies, architecture, workflow, and development process were documented.

8. Project Demonstration Phase

The completed application was demonstrated by showing user input, AI document generation, editing, and downloading the final document.
